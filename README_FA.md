# هم‌مسیر — نسخه ۰٫۴ (اینترنت + SMS سیم‌کارت)

- اینترنت برای همگام‌سازی اصلی
- صف محلی نمونه برای نگهداری تغییرات آفلاین
- کلاس `SimSmsFallback` برای ارسال مستقیم SMS با سیم‌کارت، پس از اعطای مجوز
- اسکلت Cloud Functions و Firebase

توجه: ارسال SMS به رابط کاربری متصل نشده و دریافت خودکار پیامک روی گوشی مدیر/ثبت آن در سرور هنوز پیاده‌سازی نشده است. پروژه APK آماده نیست. جزئیات در `SMS_OFFLINE_ARCHITECTURE_FA.md`.
